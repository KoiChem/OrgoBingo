# 設定画面の改訂（2026-10-30）

合意された範囲は、用語の「マスターデータ」「ビンゴセット」への統一、設定内ドロップダウンの廃止、一覧と詳細編集の分離、独立して開閉する分類条件、印刷へのデータ受け渡し。

- ビンゴセット選択・並べ替えは常時表示するボタン。マスターデータはコンパクトな一覧から選び、右側の詳細で既存の全編集項目を扱う。ID・構造式は読み取り専用。
- 官能基・構造、骨格、タグの絞り込みは各画面で独立し、初期状態は閉じる。開閉状態と選択条件は別に保持し、検索・編集による再描画でも維持する。
- 印刷には検索・並べ替え前の登録順の全件とONのIDを渡す。抽選・音声・ラウンドスナップショット・GitHub保存の仕組みは維持する。

Playwright MCPで1024×768と768×1024を確認。縦向きでは一覧304px・詳細411pxで横にはみ出さない。分類の閉状態・選択保持、名称編集、並べ替え時の登録順維持、ON/OFF、印刷の全件／ON対象IDの引き渡しを確認し、コンソールエラーは0件。再実行用のUI確認は `tests/settings.browser.js`。編集用基準データはブラウザー内のテスト用値を使い、GitHub書き込みは行っていない。実タブレットやプロジェクターでの確認ではない。
