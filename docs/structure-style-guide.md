# 構造式追加・修正ガイド

## 再生成

`python3 tools/structures/generate.py` を実行する。Python標準ライブラリのみでマスターに登録された全種を再生成し、化合物ID・分子式・原子団の価数・文字の重なり・添字を含む価標との衝突・cis/transを検査する。SVGのパスは直接編集しない。

生成元は `tools/structures/generate.py` の各化合物の定義。`layouts.json` は出力される座標記録。新規登録時は化合物マスターと生成定義を併せて更新し、全件検査する。

## 作図基準

- Liberation Sans Regular 2.1.5（公式配布版、SIL OFL 1.1）の字形をパス化する。フォントとライセンスは `tools/structures/fonts/` に同梱。外部フォントへの依存はない。
- 基準フォントサイズ48、添字倍率0.64、下げ量9。主文字の輪郭高は約33。文字ごとの輪郭とadvanceを使い、結合先原子の中心をアンカーにする。
- 価標は文字ダッシュではなく独立した線。標準水平線長36、線幅1.8、二重線間隔7、文字輪郭からの空き7、上下分岐の中心間隔88、外余白10（SVG座標単位）。実際の斜線長は配置に応じて決まる。
- CH3の上へ接続する場合、CH3全体の中央ではなくCの中央へ接続する。OHはO、HOはOの位置を指定する。
- C(=O)は使わずCの上下にOを展開する。CH(OH)はOHを上下へ、(CH3)3Cは分岐CH3を展開する。
- 長鎖のみ(CH2)nを使える。カルボキシ基は展開する。cis/transは結合の幾何配置で確認する。
- 骨格の新規自動レイアウトや編集UIは作らない。繰り返す原子・価標の配置だけ共通化する。

字形を増やす場合は、macOS上で `swift tools/structures/export-glyphs.swift` を実行して `glyphs.json` を更新する。通常の再生成にはSwiftやmacOSは不要。フォントの差し替え時は版・ライセンスとハッシュを確認し、比較を取り直す。

## 追加時の確認

1. 一次資料と照合し、分子式、置換位置、価数、異性体を確認する。
2. 生成検査を通し、XMLが読めることだけで合格にしない。
3. `structure-review/comparison.html` で添付例と文字高を揃えて比較する。価標の空き、炭素の中心、添字、文字の太さを確認する。
4. 全件一覧と、実アプリのメイン・履歴・設定プレビューで欠けと読みやすさを確認する。
5. 変更前後、採用値、修正理由、確認環境と未確認項目を記録する。添付例のスキャンノイズや傾きは再現しない。
