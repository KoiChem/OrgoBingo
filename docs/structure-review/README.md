## 過程と結果

1. 旧版の太字・一行の括弧表記を、参考例の通常ウェイト、展開したC=O・OH・CH3、独立した細い価標へ変更した。
2. 炭素アンカー、添字を含む輪郭との空きを数値検査し、全31件の化学式・原子団の価数・cis/transを確認した。結果は `checks.json`。
3. 字形固定用に用意された旧フォントと同梱ライセンスの版が一致しなかったため、公式Liberation Sans 2.1.5とその同梱ライセンスに揃えて再生成した。
   その後、塩素の小文字 `l` とヨウ素の大文字 `I` を区別できるよう、この2文字のみ独自の輪郭に変更した。生成元の `export-glyphs.swift` と `glyphs.json` に字形を保持している。
4. 代表図を `comparison.html` 上で参照画像と文字高を揃えて比較した。C=Oの垂直配置、OH・CH3の炭素への接続、下付き数字、文字と価標の空きが参照例と対応することを確認した。画像全体のピクセル一致は評価対象としない。
5. 31種の一覧をブラウザで表示し、全画像の読込成功、文字の欠け・価標との接触がないことを確認した。比較ページの初稿には一覧画像がセル外へ出る問題があったため、一覧を枠に収める表示に修正して撮り直した。

## 環の描画ルール改修（2026-11-14）

ユーザー提示のo-キシレン、2,4,6-トリブロモフェノール、シクロヘキセンの3図に基づく改修。目的は結合先原子までの距離の統一、環の左側のH表記、原子記号を明示した環内二重結合の見やすさの改善。

- 芳香環頂点から直接結合する原子中心までの距離を、一辺の約1.3倍から1.1倍へ変更した。独自配置のナフトールとp-フェニルアゾフェノールも対象とし、無水フタル酸の閉環Oの位置を追従させた。
- 脂環式の左側のCH2をH2Cに変更。炭素の座標は保持した。CHの場合もHCを用いる規則とした。
- シクロペンテンとシクロヘキセンのC=Cは、C中心間の辺を中心に±3.5の平行線とした。各線を文字範囲から7空く位置まで伸ばし、芳香環用の片側オフセット・追加短縮を外した。Cを省略する芳香環の内側線の比率は保持した。
- マスター・保存ID・分子式・結合グラフは変更していない。メイン・履歴・設定一覧と印刷の画像キャッシュ識別子を更新した。
