# 構造式修正・検証記録

2026-10-30。ユーザー提示の3画像は `references/`、修正前の31 SVGは `before/` に保存した。

## 過程と結果

1. 旧版の太字・一行の括弧表記を、参考例の通常ウェイト、展開したC=O・OH・CH3、独立した細い価標へ変更した。
2. 炭素アンカー、添字を含む輪郭との空きを数値検査し、全31件の化学式・原子団の価数・cis/transを確認した。結果は `checks.json`。
3. 字形固定用に用意された旧フォントと同梱ライセンスの版が一致しなかったため、公式Liberation Sans 2.1.5とその同梱ライセンスに揃えて再生成した。
4. 代表図を `comparison.html` 上で参照画像と文字高を揃えて比較した。C=Oの垂直配置、OH・CH3の炭素への接続、下付き数字、文字と価標の空きが参照例と対応することを確認した。画像全体のピクセル一致は評価対象としない。
5. 31種の一覧をブラウザで表示し、全画像の読込成功、文字の欠け・価標との接触がないことを確認した。比較ページの初稿には一覧画像がセル外へ出る問題があったため、一覧を枠に収める表示に修正して撮り直した。

## 証拠

- `comparison.png`：参考3画像、代表図、全31種。
- `all-31.png`：全31種の拡大可能な一覧。
- `app-main.png`：実アプリの構造式メイン表示と履歴。
- `checks.json`：生成時の数値検査、採用値、フォント版とSHA-256。

Chromiumのブラウザ表示と自動検査は実施済み。実iPad、実プロジェクター、WebKitブラウザでの表示は未確認。フォントの輪郭はSVGに埋め込まれているが、未実施の端末確認を代替したとは扱わない。
