# 炭化水素・ハロゲン化合物・高分子の追加（2026-11-02）

指定44種のうちエタノール・アセトアルデヒド・ベンゼンは既存登録を使用し、新規41種を追加。既存80種と既存ビンゴセットは変更せず、マスターは121種となった。

炭素数1・2の低分子は水素を独立したHと価標で展開した。環状脂肪族はCH/CH2を環の頂点に置き、シス・トランスの2-ブテンはメチル基とHの配置を描き分けた。シス-2-ペンテンはメチル基とエチル基を二重結合の同じ側に配置する。高分子2種は両端の継続結合を持つ繰り返し単位とnで表す。

新規の低分子39種はPubChem PUG RESTの分子式およびConnectivitySMILESを取得し、重原子・結合次数のグラフ同型性を独立に検査した。参照データは `hydrocarbon-pubchem.json` 、再検証は `python3 tools/structures/verify_hydrocarbon_references.py` 。立体配置は別途検査する。高分子の繰り返し単位の参照先も `docs/compound-sources.md` に記録した。

全121種について分子式・価数・字形と結合線の衝突を生成時に検査し、47件のNodeテストが通過。追加41種の作図を `hydrocarbons-overview.png` で目視確認。Playwrightでローカルのマスター121件・全画像と、追加41種を使う確認ラウンドのメイン・履歴、マスター121件の印刷プレビュー（5ページ）を確認した。
