# 芳香族マスター追加（2026-11-02）

依頼された47種を追加し、マスターを79種にした。既存セットは変更しない。

芳香環は交互二重結合の六角形で表し、環頂点は炭素原子として結合次数と暗黙のHを検査する。ナフタレンは共有辺を持つ10炭素として扱う。環の芳香族結合だけでは「炭素間不飽和結合」に分類しない。フェノールとアルコール、カルボン酸とその塩も区別する。

塩の部分は依頼に従ってONa、SO3Naと表す。アニリン塩酸塩とジアゾニウム塩はそれぞれNH3Cl、N2Clという原子団の縮約表記であり、N–Clの価標は描かない。

主な照合資料：
- https://pubchem.ncbi.nlm.nih.gov/compound/Sodium-benzenesulfonate （C6H5NaO3Sとスルホン酸塩の接続）
- https://pubchem.ncbi.nlm.nih.gov/compound/Benzene-diazonium-chloride （C6H5ClN2、ジアゾニウム塩）
- https://webbook.nist.gov/cgi/inchi?ID=C50782 （アセチルサリチル酸）
- https://webbook.nist.gov/cgi/cbook.cgi?ID=1689-82-3 （p-フェニルアゾフェノール）

生成時に全79種の分子式・原子団価数・文字の重なり・価標と字形の衝突を検査。全47点をブラウザで一覧表示して目視確認し、左向きカルボキシ基とニトロ基の結合原子を修正。ローカル設定マスターで79行、画像の読み込み失敗0件を確認した。

## 作図規則の全47種への適用

環内線は辺長に対し距離12%、長さ76%に統一した。芳香族46種を再生成し、ナトリウムエトキシドは見直して変更不要と判断した。元の32種の構造式は変更なし。

全79種について分子式、価数、文字・価標の衝突検査を実行。さらに芳香環からの放射方向、側鎖の水平・垂直、オルト2置換体の2時・4時、環内線の比率を検査し、Node40テストが通過した。

Playwrightで47点の一覧を目視確認。ローカルの設定マスター79行、全画像読み込み失敗0件。確認用ラウンドのメイン表示と履歴でも構造式画像の読み込みを確認。画像一覧は `aromatic-layout-review.html`、見た目の記録は `aromatic-layout-new.png`。

無水フタル酸の閉環に必要な2本のC−O結合は、環としての正確さを優先して斜線を維持する。今回の改訂はローカルでの作図見直しで、公開確認は含まない。

## 1置換体とTNTの公開版

ベンゼン1置換環を含む21物質を上下頂点・2時接続に変更し、側鎖の座標も水平・垂直になるよう移動した。2,4,6-トリニトロトルエン（TNT、C7H5N3O6）を追加してマスター80種、芳香族47種とした。NISTの構造・分子式を照合（資料はcompound-sources.md）。

全80種の生成検査と42テストが通過。追加48種を一覧画像で確認、設定マスター80行・全画像正常・TNTの掲載をローカルPlaywrightで確認。通常表示・印刷のSVGキャッシュ識別子を20261102-4へ更新。前回までの作図変更を含めて公開する。
