# 設定画面・A4印刷・無水マレイン酸の実装計画

承認済みの仕様：名称は「マスターデータ」「ビンゴセット」。無水マレイン酸をマスターと初期セット末尾へ追加する。任意の既存セットへは自動追加しない。

1. 化学データとSVG生成元を追加し、32件のID・分類・分子式・価数・配置を検証する。
2. 設定をPC・タブレット向けに再構成する。プルダウンを一覧ボタン・ソートボタン・ラジオへ変更し、一覧と詳細編集を分離する。検索は常設。分類・骨格・タグは独立して初期折りたたみ、選択中条件を閉じた見出しにも表示する。開閉と絞り込みを独立させ、編集・検索時にも状態を維持する。
3. 印刷API `OrgoPrint.open(compounds,{title,mode,enabledIds})` を実装する。マスターは全件のみ。セットは抽選ONのみ／全件を選び、別のチェックは設けない。登録順で左列上から下、右列へ。A4縦30件（15×2）／20件（10×2）、残余は次ページへ。印刷内容は名前と構造式のみ。未反映の名称もスナップショットで反映し、検索・ソートには左右されない。
4. 境界件数、データ保持、折りたたみ、PC・タブレット縦横、画像の読込、実寸PDFを確認する。実プリンター・実iPadでの確認とは区別する。
5. 変更資産の版を揃え、差分検査・commit・push、Pages成功、公開URLの新資産と主要操作を確認する。

所有範囲：設定担当はapp.js/index.html/style.css、印刷担当はprint関連ファイル、統合担当はdata/structures/toolsおよび公開。既存の音声・抽選・保存の変更は必要な接続箇所に限定する。

本追加仕様は旧仕様書の表示方法より優先する。一覧の全フィールドを常時インライン編集する必要はなく、全項目を保持して詳細編集へ分ける。スマホ設定画面は今回の最適化対象外。分類の開閉で値を消さず、未反映の編集も維持する。
